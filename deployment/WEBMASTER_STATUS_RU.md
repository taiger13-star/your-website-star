# Рекомендация Яндекс Вебмастера — 05.11.2026

Найдена одна рекомендация: **«Главный адрес сайта не использует HTTPS-протокол»**,
известная Яндексу с 20.10.2026. Она относится к ресурсу `http://noir-atelier.ru/`.
«21 самостоятельная проверка» в кабинете — список проверок, а не 21 найденная ошибка.

В этом сеансе фактически добавлен ресурс `https://noir-atelier.ru/` и подтверждено
владение существующим HTML-файлом. После проверки кабинет показал роль
«Владелец», дату 05.11.2026 и два ресурса в списке сайтов: HTTP и HTTPS.
Повторная публикация приложения или изменение сервера не потребовались.

## Проверки сайта

Все **11 проверок прошли** с обычной проверкой доверия TLS:

| Проверка | Результат |
| --- | --- |
| HTTP/HTTPS, www/без www; главная и каталог с query | 8 проверок: 200 на HTTPS без www; остальные варианты — постраничный 301 с сохранением пути и параметров |
| canonical и индексация проверенных страниц | Один canonical на HTTPS без www; параметр метки исключён из canonical, noindex отсутствует |
| sitemap.xml | HTTP 200; 38 URL, все с origin `https://noir-atelier.ru` |
| robots.txt | HTTP 200; указан `https://noir-atelier.ru/sitemap.xml` |
| Существующий HTML-файл Яндекса | HTTP 200; содержимое подтверждено; файл принят при проверке владения |

В этом сеансе проверено содержимое sitemap, а не повторно запрошены все 38 её
страниц. Полная проверка всех URL выполнена при публикации и описана в
[PUBLISH_STATUS_RU.md](PUBLISH_STATUS_RU.md).

## Что мешает закончить

Яндекс непосредственно в инструменте «Переезд сайта» сообщает:

> Инструмент «Переезд сайта» работает в режиме «Только для чтения».

После подтверждения обоих ресурсов повторно выбраны «Добавить HTTPS» и
адрес `https://noir-atelier.ru`; «Добавить WWW» выключено. Кнопка
«Сохранить» остаётся недоступной. **Заявка не отправлена, переезд в поиске
не подтверждён, рекомендация не отмечена устранённой.** Выбор в форме не
является сохранённой настройкой.

Инструмент «Файлы Sitemap» также сообщает о режиме только для чтения:
кнопка «Добавить» отключена. Ручная отправка карты не выполнена.
Карта уже доступна поисковому роботу через robots.txt.
Диагностика предупреждает о временно недоступном обновлении данных.

## Следующий шаг после восстановления сервиса

1. Открыть [переезд HTTP-ресурса](https://webmaster.yandex.ru/site/http:noir-atelier.ru:80/indexing/mirrors/).
2. Выбрать тот же домен, включить «Добавить HTTPS», оставить «Добавить WWW»
   выключенным. Проверить итоговый адрес `https://noir-atelier.ru` и нажать
   «Сохранить», когда кнопка станет доступна.
3. Убедиться, что кабинет принял заявку. Принятая заявка ещё не означает
   завершённый переезд в поиске.
4. В HTTPS-ресурсе открыть «Индексирование → Файлы Sitemap» и добавить
   `https://noir-atelier.ru/sitemap.xml`, только если его ещё нет в списке.
5. Проверить результат обработки в Вебмастере: главный адрес и страницы в поиске.

Порядок соответствует [официальной инструкции Яндекса по переходу на HTTPS](https://yandex.ru/support/webmaster/ru/yandex-indexing/https-migration).
Автоматическое повторение действий и изменение других настроек аккаунта не настроены.

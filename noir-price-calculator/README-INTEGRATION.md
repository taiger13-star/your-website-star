# NOIR ATELIER — калькулятор стоимости

Модуль рассчитан на текущий проект `taiger13-star/your-website-star`
(TanStack Start + React).

Покупатель выбирает изделие, размер, STANDARD/SMART, материал и цвет.
После изменения параметров сайт вызывает серверную функцию и показывает
только итоговую цену.

Закупочная цена материала за 1 кг, матрица материал×цвет и коэффициенты
не отправляются в браузер.

## Где вы меняете цены

В серверных Secrets / Environment Variables проекта задайте:

`NOIR_MATERIAL_PRICES_JSON`

Пример структуры:

```json
{
  "PLA": {"default": 0, "ivory": 0, "black": 0},
  "PETG": {"default": 0},
  "TPU": {"default": 0}
}
```

Нули заменяются вашими реальными закупочными ценами за 1 кг.

Дополнительно:
- `NOIR_REFERENCE_MATERIAL_COST_RUB_KG` — себестоимость 1 кг, уже заложенная в текущие базовые цены.
- `NOIR_MATERIAL_DELTA_MULTIPLIER` — коэффициент, с которым изменение себестоимости влияет на розничную цену.
- `NOIR_MINIMUM_PRODUCT_PRICE_RUB` — минимальная цена товара.

Формула сохраняет существующую базовую цену каталога и корректирует её
по скрытой стоимости выбранного материала/цвета и весу изделия.

Если секретные тарифы ещё не заполнены, калькулятор показывает текущую
базовую цену каталога.

После копирования файлов запустите `npm run build`.
TanStack Router сам обновит `src/routeTree.gen.ts`.

Для ссылки в меню добавьте в `NAV_LINKS`:
`{ label: "Калькулятор", to: "/calculator" },`

Если нужна закрытая админка `/admin/pricing`, где цены меняются прямо на сайте,
нужно подключить постоянное серверное хранилище/БД. Себестоимость нельзя
хранить в публичном React/JSON-конфиге или localStorage — её увидит клиент.
